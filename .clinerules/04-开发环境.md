# Windows 开发环境陷阱

## PowerShell 陷阱
- `2>&1` 被解析为 Out-File 失败 → 用 `cmd /c "cargo test 2>&1"`
- `&&` 无效 → 用 `;`
- `del /q` 是 cmd 语法 → 用 Remove-Item/Rename-Item
- `$n:` 被当盘符 → 用 `("L"+$n+":")`
- `| findstr` 可能吞输出
- 中文 + 嵌套引号在命令行被拆

## 正确命令模板
cargo（必须用 cmd /c 包裹）
cmd /c "cargo check 2>&1"
cmd /c "cargo test 2>&1"

git 中文 commit（必须用 wsl）
wsl bash -c "cd /mnt/d/APO_Project/VxAPO/vxapo-driver && git add -A && git commit -m '中文提交信息'"

text

## 编辑器工具注意
- replace_in_file 多块可能只应用最后一个
- 以工具返回的 final_file_content 为基准
- 必要时 wsl cat/wc 确认真实磁盘状态
- SEARCH 块必须精确匹配当前文件内容
