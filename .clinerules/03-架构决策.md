# 已确认的架构决策（用户批准，勿再争论）

## GUID 格式化
- sys/com/prelude.rs 内：pub use StringFromGUID2 + pub fn guid_to_string
- 所有调用点统一走 prelude::guid_to_string（slots.rs / selector.rs / vx_reg_props.rs / endpoint.rs）
- guid_win crate 已被否决（依赖 winapi 而非 windows-rs）
- utils/guid.rs 已删除

## APO 类型方案（方案 A）
- apo_types.rs 中 windows-rs 已有类型全部 re-export（camelCase）
- 仅保留 windows-rs 缺失的自定义项
- #[interface] / 自创 APO trait 是错的，应 re-export windows-rs 结构体 + *_Impl trait

## DSP 工厂架构
- Filter: Send + Sync + Debug，process(&mut [Vec<f32>], usize)，RT-safety 无分配无锁
- FilterFactory::create_filter(&self, params, ctx:&DspContext, loader:&dyn ConfigLoader) -> FilterCreateResult
- FilterCreateResult: Filter / NoFilter / NoMatch / AbortFile
- FilterRegistry::try_create 遍历所有已注册工厂
- FACTORY_COUNT=15，index 常量 0-14 对应注册顺序

## IIRFactory 类型覆盖
- PK/PEAK → PeakingFilter
- LP/HP → HighLowPassFilter
- LS/HS/AP/NO → compute_coeffs + BiquadFilter（临时封装）
- Modal → NoMatch（不报错，留未来扩展）

## config/parser 命令分发
- parse_lines_impl 中 registry.try_create(value) 分发 DSP 命令
- 纯配置命令（Device/If/Stage/Channel/Eval/Include）经命令处理器
- NullConfigLoader 为 pub(crate)

## clippy 策略（方案 2）
- 功能骨架优先，clippy 集中收尾
- lib.rs 的 #![deny(clippy::undocumented_unsafe_blocks)] 造成的 SAFETY 注释需求暂冻结
- 待功能定型后统一处理

## audiodg 测试
- 使用独立子键 test_path(name) 避免并行竞态
- 用 eprintln 调试定位（用户坚持，不要瞎猜）
