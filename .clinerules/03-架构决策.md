## DSP 工厂架构
- Filter: Send + Sync + Debug，process(&mut [Vec<f32>], usize)，RT-safety 无分配无锁
- FilterFactory::create_filter(&self, params, ctx:&DspContext, loader:&dyn ConfigLoader) -> FilterCreateResult
- FilterCreateResult: Filter / NoFilter / NoMatch / AbortFile
- FilterRegistry::try_create 遍历所有已注册工厂
- FACTORY_COUNT=15，index 常量 0-14 对应注册顺序

## IIRFactory 类型覆盖
- PK/PEAK → PeakingFilter
- LP/HP → HighLowPassFilter
- LS/HS/AP/NO → compute_coeffs + BiquadFilter（临时封装）
- Modal → NoMatch（不报错，留未来扩展）

## Convolution 实现方案（Phase 8 选定：短 IR 时域）
- IR < 256 采样：直接时域 FIR 卷积（环形延迟线，RT 安全无分配无锁）
- latency = ir_len - 1 如实报告；增益线性合并进 IR 系数
- WAV 解析：PCM16 / f32，单声道 IR 复制多通道，1 MiB 大小上限
- 长 IR（≥256）或加载失败：跳过该滤波器 + log warn（不报错）
- 长 IR 的分段卷积（Partitioned）留待未来
